# Support & Community Help

Thank you for using `EricksonLopez.Transaction`! This document outlines available channels for getting assistance, reporting issues, and discussing architectural patterns.

---

## 💬 Getting Help

### 1. GitHub Discussions
Use [GitHub Discussions](https://github.com/ericksonlopezf/dotnet-transaction/discussions) for:
- Architectural advice and design questions.
- Guidance on integrating `EricksonLopez.Transaction` with other ecosystem libraries (e.g., `EricksonLopez.Result`, Dapper, Npgsql, EF Core).
- Sharing recipes, best practices, and use-case feedback.

### 2. GitHub Issues
Use [GitHub Issues](https://github.com/ericksonlopezf/dotnet-transaction/issues) strictly for:
- Reproducible bug reports.
- Feature suggestions and enhancements aligned with the library's architectural scope.

*Note: For security vulnerabilities, please refer to [SECURITY.md](SECURITY.md).*

### 3. Documentation & Showcase
- **Documentation**: Browse [`docs/`](docs/) for architectural specifications, package references, and CI/CD quality standards.
- **Showcase**: Run `dotnet run --project samples/Showcase/EricksonLopez.Transaction.Showcase.csproj --framework net10.0 -- --all` for 11 executable code levels demonstrating all public APIs.
